1. Todo arquivo novo nasce completo.

2. Toda alteração é enviada com o arquivo completo.

3. Nenhuma etapa continua sem compilar.

4. Nenhuma etapa continua sem testar.

5. Commits somente quando tudo estiver funcionando.

6. Não criar código "para usar depois".

7. Nunca duplicar responsabilidade entre arquivos.

8. Quando houver refatoração, primeiro mover, depois melhorar.
